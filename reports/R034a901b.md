# PAC Learning Shows When Examples Suffice

PAC learning answers a basic question: **when can examples support a rule that predicts well on new cases, rather than merely memorizing the examples?** In supervised classification, an example is an input, a label says which category it belongs to, a hypothesis is a candidate prediction rule, and a learning algorithm chooses a rule from the labeled examples ([PAC Learning Framework](https://www.niser.ac.in/~smishra/teach/cs460/2020/lectures/lec7_1/); [PAC Learning](https://www.mathematik.uni-muenchen.de/~deckert/teaching/SS17/ATML/media/PAC_learning_notes.pdf)). The basic theorem says that, under specific assumptions, enough independently sampled examples make it unlikely that a rule fitting every example will still make many mistakes on future cases ([Berkeley lecture notes](https://people.eecs.berkeley.edu/~nika/courses/cs272/f25/02-consistency-pac.pdf)). “Approximately correct” means the rule’s error is no greater than a chosen tolerance, \(\epsilon\); “probably” means this happens with probability at least \(1-\delta\), where \(\delta\) is the allowed chance of failure ([PAC Learning Framework](https://www.niser.ac.in/~smishra/teach/cs460/2020/lectures/lec7_1/)). For a finite set of candidate rules in the realizable setting, a sufficient sample size is \(m\geq(\ln|\mathcal H|+\ln(1/\delta))/\epsilon\), where \(m\) is the number of examples and \(|\mathcal H|\) is the number of candidate rules ([Berkeley lecture notes](https://people.eecs.berkeley.edu/~nika/courses/cs272/f25/02-consistency-pac.pdf)). This is a statistical guarantee under stated assumptions—not a promise that every prediction is right, that the bound is the smallest possible, or that finding the rule is easy.

## PAC measures mistakes on future examples

Consider a simple task such as deciding whether an email is spam. An input \(x\) describes an email; its label \(y\) is one of two categories, written \(0\) and \(1\); and a hypothesis \(h\) is a rule that predicts one of those labels for each possible input ([PAC Learning Framework](https://www.niser.ac.in/~smishra/teach/cs460/2020/lectures/lec7_1/)). A learning algorithm takes a sample \(S\) of labeled examples and returns a hypothesis, written \(A(S)\) ([PAC Learning](https://www.mathematik.uni-muenchen.de/~deckert/teaching/SS17/ATML/media/PAC_learning_notes.pdf)). The set of candidate rules is the hypothesis class, \(\mathcal H\). In the **realizable** version of PAC learning, the correct labeling rule belongs to \(\mathcal H\), so at least one candidate can label every example correctly ([Berkeley lecture notes](https://people.eecs.berkeley.edu/~nika/courses/cs272/f25/02-consistency-pac.pdf)).

The setting also assumes a distribution \(D\): a description of how likely different inputs are in the population where the rule will be used. Writing \(x\sim D\) means that \(x\) is drawn according to that distribution. The basic theorem assumes that examples are independent draws from the same fixed \(D\), and that a target rule \(c\) supplies their labels ([PAC Learning Framework](https://www.niser.ac.in/~smishra/teach/cs460/2020/lectures/lec7_1/); [Valiant, “A Theory of the Learnable”](https://courses.grainger.illinois.edu/ece544na/fa2014/valiant84.pdf)). “Independent” means one draw does not affect another; “identically distributed” means each draw uses the same \(D\). The guarantee allows \(D\) to be arbitrary, but it does not remove these sampling assumptions ([PAC Learning Framework](https://www.niser.ac.in/~smishra/teach/cs460/2020/lectures/lec7_1/)).

The **true error** of a rule is its chance of disagreeing with the target on a new example:

\[
R_D(h)=\Pr_{x\sim D}[h(x)\ne c(x)].
\]

Here, \(\Pr\) means probability—the chance that an event happens—and \(h(x)\ne c(x)\) means the rule and target give different labels. Thus \(R_D(h)\) is the probability of a mistake on one fresh draw from \(D\) ([PAC Learning](https://www.mathematik.uni-muenchen.de/~deckert/teaching/SS17/ATML/media/PAC_learning_notes.pdf)).

The **empirical error** is the fraction of observed examples that the rule gets wrong. If the sample has \(m\) examples, let \(I_i=1\) when \(h\) gets example \(i\) wrong and \(I_i=0\) when it gets that example right. Then

\[
\widehat R_S(h)=\frac{1}{m}\sum_{i=1}^{m} I_i.
\]

The sum counts mistakes; dividing by \(m\) turns the count into a fraction ([PAC Learning](https://www.mathematik.uni-muenchen.de/~deckert/teaching/SS17/ATML/media/PAC_learning_notes.pdf)). For a fixed rule, each \(I_i\) equals 1 with probability \(R_D(h)\). The average of the indicators therefore has expected value

\[
\mathbb E[\widehat R_S(h)]
=\frac{1}{m}\sum_{i=1}^{m}\mathbb E[I_i]
=\frac{1}{m}\sum_{i=1}^{m}R_D(h)
=R_D(h).
\]

The first equality substitutes the definition of empirical error; the second uses the fact that the expectation of a sum is the sum of its expectations; the last averages \(m\) identical values. So empirical error is an unbiased estimate of true error, but one particular sample can still miss mistakes ([PAC Learning](https://www.mathematik.uni-muenchen.de/~deckert/teaching/SS17/ATML/media/PAC_learning_notes.pdf)).

## The finite-class guarantee follows from counting bad rules

The standard realizable PAC guarantee is

\[
\Pr_{S\sim D^m}\!\left[R_D(A(S))\leq\epsilon\right]\geq 1-\delta.
\]

Here \(D^m\) means a sample of \(m\) independent draws from \(D\); \(\epsilon\) is the largest tolerated true error; and \(\delta\) is the largest tolerated chance that the learned rule exceeds that error ([PAC Learning Framework](https://www.niser.ac.in/~smishra/teach/cs460/2020/lectures/lec7_1/); [Berkeley lecture notes](https://people.eecs.berkeley.edu/~nika/courses/cs272/f25/02-consistency-pac.pdf)). The probability is over which training sample happens to be drawn, not over whether every future prediction is correct.

To obtain a sample bound, first consider one fixed “bad” hypothesis \(h\), meaning \(R_D(h)>\epsilon\). It has probability \(1-R_D(h)\) of agreeing with the target on one example. Independence lets us multiply that chance across all \(m\) examples:

\[
\Pr(h\text{ fits all }m\text{ examples})=(1-R_D(h))^m
\leq(1-\epsilon)^m.
\]

The final inequality follows because \(R_D(h)>\epsilon\), so \(1-R_D(h)<1-\epsilon\) ([Berkeley lecture notes](https://people.eecs.berkeley.edu/~nika/courses/cs272/f25/02-consistency-pac.pdf)).

There may be many bad hypotheses. The union bound says that the chance at least one of several events occurs is no greater than the sum of their individual chances. Since there are \(|\mathcal H|\) candidates, the probability that any bad one fits the sample is at most

\[
|\mathcal H|(1-\epsilon)^m.
\]

For a simpler expression, use \(1-\epsilon\leq e^{-\epsilon}\), where \(e\) is the base of natural logarithms. One justification is to define \(g(x)=e^{-x}-(1-x)\). Since \(g(0)=0\) and its derivative \(g'(x)=1-e^{-x}\) is nonnegative for \(x\geq0\), \(g(x)\) cannot fall below zero. Setting \(x=\epsilon\) gives the inequality. Applying it to the probability bound gives \(|\mathcal H|e^{-m\epsilon}\) ([Cornell, PAC learning lecture notes](https://www.cs.cornell.edu/courses/cs6781/2020sp/lectures/03-pac1.pdf)).

Require this upper bound on failure to be no more than \(\delta\):

\[
|\mathcal H|e^{-m\epsilon}\leq\delta.
\]

Divide by \(|\mathcal H|\) and take natural logarithms, which turn exponentials into their exponents:

\[
e^{-m\epsilon}\leq\frac{\delta}{|\mathcal H|}
\quad\Longrightarrow\quad
-m\epsilon\leq\ln\delta-\ln|\mathcal H|.
\]

Dividing by \(-\epsilon\) reverses the inequality because the divisor is negative. Since \(-\ln\delta=\ln(1/\delta)\), this yields

\[
m\geq\frac{\ln|\mathcal H|+\ln(1/\delta)}{\epsilon}
=\frac{1}{\epsilon}\ln\frac{|\mathcal H|}{\delta}.
\]

This is a sufficient sample bound for a finite class in the realizable setting when the learner returns a hypothesis consistent with the sample ([Berkeley lecture notes](https://people.eecs.berkeley.edu/~nika/courses/cs272/f25/02-consistency-pac.pdf); [Munich lecture notes](https://www.mathematik.uni-muenchen.de/~deckert/teaching/SS17/ATML/media/PAC_learning_notes.pdf)). It grows as the demanded error tolerance \(\epsilon\) shrinks, and it grows logarithmically as the class gets larger or the tolerated failure probability \(\delta\) gets smaller.

## A four-position example makes error and sample size concrete

Suppose there are four possible inputs, positions \(1,2,3,4\), and each occurs with probability \(1/4\). Their true labels are \(0,0,1,1\), respectively. Consider four candidate rules, each of which labels positions up to a cutoff as 0 and positions above it as 1:

\[
\mathcal H=\{h_1,h_2,h_3,h_4\},\qquad
h_k(x)=
\begin{cases}
0,&x\leq k,\\
1,&x>k.
\end{cases}
\]

The correct rule is \(h_2\), and the class has \(|\mathcal H|=4\). This is a constructed illustration of the standard PAC definitions, not a reported experiment ([Cornell, PAC learning lecture notes](https://www.cs.cornell.edu/courses/cs6781/2020sp/lectures/03-pac1.pdf)).

Suppose the observed sample contains positions \(1\) and \(4\), with labels \(0\) and \(1\). Rule \(h_1\) gets both observed labels right, so its empirical error is \(0/2=0\). But it labels position \(2\) as 1 when the true label is 0. Since that position occurs with probability \(1/4\), \(h_1\)'s true error is \(1/4\). The sample’s zero observed mistakes do not prove zero future error: this sample simply missed the position where the rule fails.

Now choose a tolerated error \(\epsilon=0.25\) and failure probability \(\delta=0.10\). Substituting the four candidate rules into the sufficient bound gives

\[
m\geq\frac{1}{0.25}\ln\frac{4}{0.10}
=4\ln(40)\approx14.76.
\]

Because a sample must contain a whole number of examples and meet or exceed the bound, round up to \(15\). Under the theorem’s assumptions, this means a consistent learner’s output has true error at most \(25\%\) with probability at least \(90\%\) over the random sample ([MIT 6.045J Lecture 20: More PAC Learning](https://ocw.mit.edu/courses/6-045j-automata-computability-and-complexity-spring-2011/a67f4e0606f402e56f85a736578e7f13_MIT6_045JS11_lec20.pdf); [Some Basic Notions of Machine Learning, Proposition 1.1.25](https://home.mathematik.uni-freiburg.de/maxwell/coursenotes-mlandml-website.pdf)). This is a sufficient bound, not a claim that every sample of that size succeeds or that \(15\) is the minimum needed. In this particular four-position distribution, errors occur in increments of \(1/4\), so an error of at most \(0.10\) would require no mistakes at all; that is a feature of the toy example, not a general meaning of \(\epsilon=0.10\) ([Cornell, PAC learning lecture notes](https://www.cs.cornell.edu/courses/cs6781/2020sp/lectures/03-pac1.pdf)).

A stricter illustrative choice shows how the bound changes: with the same \(|\mathcal H|=4\), but \(\epsilon=0.10\) and \(\delta=0.05\), it gives \(m\geq10(\ln4+\ln20)=10\ln80\approx43.82\), which rounds up to \(44\) examples ([University of Maryland, Learning Bounds for Finite \(H\), Consistent Case](https://www.cs.umd.edu/~jbg/teaching/CSCI_5622/05a.pdf)). The exact pre-exponential condition for the earlier choice is \(4(1-0.25)^m\leq0.10\), which is satisfied from \(m=13\); the standard exponential simplification gives the more conservative sufficient bound of \(15\) ([MIT 6.045J Lecture 20: More PAC Learning](https://ocw.mit.edu/courses/6-045j-automata-computability-and-complexity-spring-2011/a67f4e0606f402e56f85a736578e7f13_MIT6_045JS11_lec20.pdf)). Different sufficient bounds need not be minimum sample counts.

## Variants extend the result but do not remove its limits

The realizable theorem assumes a perfect rule exists in the class. In the **agnostic** setting, labels may be noisy or no candidate rule may be perfect. The aim changes: instead of promising small absolute error, the learner aims to be within \(\epsilon\) of the best rule in \(\mathcal H\), written \(L_D(\hat h)\leq\inf_{h\in\mathcal H}L_D(h)+\epsilon\) ([MIT 6.790, “Learnability and VC Dimension”](https://gradml.mit.edu/supervised/learnability-and-vc/)). Here \(L_D(h)\) is expected loss on the data distribution and the infimum is the best loss available within the class. This guarantee does not imply that the best available rule has low error.

For a finite class with losses between 0 and 1, empirical risk minimization (ERM) selects \(\hat h\) with the smallest average sample loss. If every candidate’s sample loss is within \(\epsilon/2\) of its expected loss, then for any comparison rule \(h^*\),

\[
L_D(\hat h)\leq L_S(\hat h)+\epsilon/2
\leq L_S(h^*)+\epsilon/2
\leq L_D(h^*)+\epsilon.
\]

The first and last inequalities use the assumed \(\epsilon/2\) closeness; the middle uses ERM’s definition. Taking the best comparison rule gives the agnostic guarantee ([MIT 6.790, “Learnability and VC Dimension”](https://gradml.mit.edu/supervised/learnability_and_vc/)). A Hoeffding concentration bound, followed by summing failure probabilities over the finite class, gives the sufficient sample size

\[
m\geq\frac{2}{\epsilon^2}\ln\frac{2|\mathcal H|}{\delta}
\]

for this bounded-loss ERM result ([Utrecht University, “PAC Learning and the VC Dimension”](https://ics-websites.science.uu.nl/docs/vakken/mbd/slides/PAC-and-VC.pdf)). The \(\epsilon^{-2}\) dependence differs from the realizable \(\epsilon^{-1}\) bound because the proof controls deviations between observed and expected losses rather than asking whether a bad rule can fit every example. For losses in \([a,b]\), the corresponding sufficient bound scales with \((b-a)^2\), reflecting the range of possible losses ([Utrecht University, “PAC Learning and the VC Dimension”](https://ics-websites.science.uu.nl/docs/vakken/mbd/slides/PAC-and-VC.pdf)).

A class may contain infinitely many rules, so simply counting them no longer works. **VC dimension** measures how many points a class can label in every possible binary way: a set is “shattered” if every possible labeling of that set is achievable by some rule in the class ([MIT 6.790, “Learnability and VC Dimension”](https://gradml.mit.edu/supervised/learnability_and_vc/)). Finite VC dimension limits the number of distinct label patterns the class can produce on finite samples, allowing sample guarantees to depend on effective capacity rather than the literal number of rules. Standard rates reported for VC classes scale, up to constants, as \((d\log(1/\epsilon)+\log(1/\delta))/\epsilon\) in one realizable ERM result and as \((d+\log(1/\delta))/\epsilon^2\) in an agnostic result, where \(d\) is the VC dimension ([MIT 6.790, “Learnability and VC Dimension”](https://gradml.mit.edu/supervised/learnability_and-vc/)). These advanced rates use capacity and concentration results beyond the finite-class derivation above. Finite VC dimension characterizes learnability in the cited binary-classification setting; it does not imply every infinite class is learnable, nor does it guarantee an efficient algorithm ([MIT 6.790, “Learnability and VC Dimension”](https://gradml.mit.edu/supervised/learnability_and-vc/); [Purdue University, “A Theory of PAC Learnability of Partial Concept Classes”](https://web.ics.purdue.edu/~hanneke/docs/2021/A_Theory_of_PAC_Learnability_of_Partial_Concept_Classes.pdf)).

Finally, sample complexity and computational complexity are different questions. A theorem can say that enough examples suffice without showing that a practical algorithm can find a consistent rule efficiently ([Columbia University, “Introduction to PAC Learning”](https://www.cs.columbia.edu/~aho/cs3261/Lectures/L22-Introduction_to_PAC_Learning.html)). PAC guarantees also concern a fixed distribution: if future cases come from a different distribution, the guarantee alone does not bound performance there ([Princeton University, “COS324: Introduction to Machine Learning — Lecture 4: PAC Learning, Part I”](https://www.cs.princeton.edu/courses/archive/fall17/cos324/lectures/lect4.pdf)). Nor does the theorem choose a suitable hypothesis class or ensure its best rule is good; the agnostic guarantee is only relative to that class ([MIT 6.790, “Learnability and VC Dimension”](https://gradml.mit.edu/supervised/learnability_and_vc/)). Valiant’s original motivation was to formalize when machines can infer recognition procedures from information and whether they can do so with feasible computational effort; the modern introductory finite-class theorem isolates the statistical part of that broader question ([Valiant, “A Theory of the Learnable”](https://courses.grainger.illinois.edu/ece544na/fa2014/valiant84.pdf)).

## Conclusion

PAC learning turns “learn from examples” into a precise statement about future performance: specify an error tolerance, a failure probability, a class of candidate rules, and assumptions about how examples are drawn. Its finite-class proof is simple in spirit—bad rules are unlikely to fit enough independent examples, and a finite class lets us bound the chance that any such rule escapes detection.

The theorem is most useful when read with its conditions attached. It supports confidence about performance on data from the same distribution, but does not settle whether the class is appropriate, the labels are trustworthy, future data will remain comparable, or the learning procedure is computationally practical.
