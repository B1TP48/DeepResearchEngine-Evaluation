# How PAC Learning Turns Examples Into Guarantees

**Probably Approximately Correct (PAC) learning**, introduced by Leslie Valiant in 1984, is a mathematical definition of when a machine can learn a rule from examples. A learner is judged successful if, with high probability, it produces a rule that is almost always right on new cases. The framework answers two questions: how many examples are enough, and whether the learning can be done in reasonable time. For a finite set of candidate rules, the realizable (noise-free) case needs about $\frac{1}{\varepsilon}\left(\ln|H| + \ln\frac{1}{\delta}\right)$ examples, where $\varepsilon$ is the allowed error and $\delta$ is the allowed chance of failure. Valiant's paper is the origin of the name, but the model it formulates differs from the textbook version that followed, and a 2026 preprint makes this point explicitly ([Valiant, ACM](https://dl.acm.org/doi/10.1145/1968.1972); [arXiv 2605.13840](https://arxiv.org/html/2605.13840v1)). The framework matters because it gives machine learning a precise standard of success and shows that learning can be analyzed as a computational problem. It also has limits: it applies cleanly to a narrow class of problems, and some classes are provably hard to learn efficiently ([Davis review](https://cs.nyu.edu/~davise/papers/Valiant.pdf)). Valiant received the 2010 ACM A.M. Turing Award, in part for PAC learning ([Turing Award citation](https://www.codes-isss.org/amturing_subdomain/award_winners/valiant_2612174/)).

## Learning as recovering a hidden rule from labelled examples

Machine learning is the automated detection of meaningful patterns in data so that a program can make correct predictions on new cases ([Shalev-Shwartz and Ben-David, Preface](https://www.cambridge.org/core/books/abs/understanding-machine-learning/preface/78FF9A254F682A1E33037CE2D82B4270)). The PAC setup makes this concrete. Each possible input (an email, an image, a patient record) is a point in an **instance space** $X$, the set of all possible inputs. A **concept** is the true rule that sorts inputs into two groups, and it can be represented as a function $c : X \to \{0,1\}$ that outputs 1 for members and 0 for non-members. A **concept class** $C$ is a collection of such possible rules ([Wikipedia, PAC learning](https://en.wikipedia.org/wiki/Probably_approximately_correct_learning); [Worrell, FoPPS lecture notes](https://www.mimuw.edu.pl/~fopss18/PDF/Worrell-lecture-notes.pdf)).

The learner never sees the rule itself. It sees a **training sample** $S = (z_1, \ldots, z_m)$, a list of $m$ **labelled examples** $z_i = (x_i, c(x_i))$. Each example is produced by drawing an input at random and attaching its correct label ([Wikipedia, PAC learning](https://en.wikipedia.org/wiki/Probably_approximately_correct_learning)). From this sample, the learner outputs a **hypothesis** $h$, its own guess at the rule. The set of rules it may choose from is the **hypothesis class** $H$. Textbooks differ on naming: Wikipedia and Worrell write $C$ for the class of concepts, while Shalev-Shwartz and Ben-David write $H$ for the hypothesis class ([MDPI, Understanding Machine Learning Principles](https://www.mdpi.com/2227-7390/13/3/451)). The core task is therefore: the true rule is unknown, the learner sees labelled examples, and it must output a rule that works on inputs it has not seen. Shalev-Shwartz and Ben-David describe this as moving from individual examples to broader generalization, since memorizing examples cannot label unseen email ([Shalev-Shwartz and Ben-David, Chapter 1](https://www.cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf)).

## What "probably", "approximately" and "correct" each guarantee

The three words correspond to two parameters and one goal. Let $D$ be the **distribution** that says how often each input appears. It is fixed but unknown. The **error** of a hypothesis $h$ is the probability that it disagrees with the true rule on a fresh random input:

$$\mathrm{err}_D(h) = P_{x \sim D}\big[h(x) \neq c(x)\big]$$

Here $P_{x\sim D}[\cdot]$ means "the probability, when $x$ is drawn from $D$, that the statement holds." If $D$ puts most of its weight on ordinary emails, the error counts mistakes on ordinary emails. "Correct" in the PAC sense means the learner aims to match the true rule up to this error, not to be right on every input. Exact learning requires the output to equal the target every time, while PAC learning relaxes this because an approximately correct answer is often enough ([UT Austin lecture notes, CS 395T](https://www.cs.utexas.edu/~klivans/f06lec2.pdf)).

"Approximately" is the accuracy parameter $\varepsilon \in (0,1)$: the learned rule must have error at most $\varepsilon$. "Probably" is the confidence parameter $\delta \in (0,1)$: the guarantee must hold with probability at least $1-\delta$. The learner may therefore fail with probability $\delta$, and this failure event is the only thing $\delta$ controls ([Wikipedia, PAC learning](https://en.wikipedia.org/wiki/Probably_approximately_correct_learning); [Class Notes 67577, arXiv 0904.3664](https://arxiv.org/pdf/0904.3664)).

Putting these together gives the central definition. In the realizable setting, where the true rule lies in the class, a class $H$ is **PAC learnable** if there is an algorithm $A$ and a function $m(\varepsilon,\delta)$ such that for every distribution $D$ and every $\varepsilon, \delta \in (0,1)$: when $A$ receives $m \ge m(\varepsilon,\delta)$ independent examples, it outputs $\hat h$ with

$$P\big[\mathrm{err}_D(\hat h) \le \varepsilon\big] \ge 1-\delta.$$

The probability is over the random training sample. The phrase "for every distribution" is why the model is called **distribution-free**: the learner must work whatever $D$ is ([Wikipedia, PAC learning](https://en.wikipedia.org/wiki/Probably_approximately_correct_learning)). The term $m(\varepsilon,\delta)$ is the **sample complexity**, the number of examples needed. The definition also asks for efficiency: the running time should grow only polynomially in $1/\varepsilon$, $\ln(1/\delta)$, and the size of the problem ([Hebrew University lecture notes](https://www.cs.huji.ac.il/w~shashua/papers/class10-PAC1.pdf)).

### The probability facts the definition relies on

Two basic probability ideas carry the whole framework. First, a probability is a number from 0 to 1. The complement rule states $P(\text{not } A) = 1 - P(A)$, so "the failure event has probability at most $\delta$" is the same as "success has probability at least $1-\delta$." Second, PAC analysis assumes the training examples are **independent and identically distributed (i.i.d.)**. Independence means one draw does not change the chances of another, and identically distributed means every draw uses the same probability model. A fair coin gives heads with probability 0.5 on each toss, and a die gives any given face with probability 1/6 on each roll ([Statology, i.i.d. random variables](https://www.statology.org/i-i-d-random-variables/)). Drawing cards without replacement fails the test, because each removed card changes the next draw ([aiwiki.ai, i.i.d.](https://aiwiki.ai/wiki/independently_and_identically_distributed_i_i_d)). Because i.i.d. is often assumed rather than proven, the PAC guarantee holds exactly when the examples really are independent draws from one distribution ([Wikipedia, i.i.d. random variables](https://en.wikipedia.org/wiki/Independent_and_identically_distributed_random_variables)).

For independent events, the probability that all of them happen is the product of their probabilities. If each of $m$ independent examples has probability $p$ of matching, then all $m$ match with probability $p^m$. This product rule is the engine behind the sample-size formulas below.

## A finite class needs about (1/ε)(ln|H| + ln(1/δ)) examples

Suppose $H$ is finite, with $|H|$ members, and the true rule $c$ is in $H$ (the realizable case). The **consistency learner** outputs any hypothesis that agrees with every training label. The following theorem gives a sample size that guarantees success.

**Theorem.** If $m \ge \frac{1}{\varepsilon}\left(\ln|H| + \ln\frac{1}{\delta}\right)$, then with probability at least $1-\delta$ every consistent hypothesis has error at most $\varepsilon$. Equivalently, the consistency learner PAC-learns $H$ with this sample size ([Zhang, CSC 665 PAC notes](https://zcc1307.github.io/courses/csc665fa19/notes/pac.pdf)).

Each term has a plain meaning. $\ln|H|$ measures how many rules the learner must rule out, since more candidates need more evidence. $\ln(1/\delta)$ measures the price of confidence, and shrinking $\delta$ costs only logarithmically. $1/\varepsilon$ measures the price of accuracy: a rule with error above $\varepsilon$ is caught by each example with probability at least $\varepsilon$, so the evidence accumulates as $\varepsilon m$.

**Derivation, step by step.** The proof needs three facts that the sources use but do not all prove. We state them with their own short justifications.

*Fact 1 (union bound).* For events $A_1,\ldots,A_t$, the probability that at least one occurs is at most the sum of their probabilities: $P(A_1\cup\cdots\cup A_t) \le \sum_i P(A_i)$ ([Livni, COS-511 lecture notes](https://www.cs.princeton.edu/~rlivni/cos511/lectures/lect2.pdf)). It holds because the sum counts every outcome in the union at least once.

*Fact 2 (the inequality $1-x \le e^{-x}$).* For all real $x$, $1 - x \le e^{-x}$. Proof: let $f(x) = e^{-x} - (1-x)$. Then $f(0) = 0$ and $f'(x) = 1 - e^{-x}$, which is $\ge 0$ for $x\ge 0$ and $\le 0$ for $x \le 0$. So $f$ attains its minimum at $0$, giving $f(x) \ge 0$. (The notes did not cite a source for this inequality, so this proof is supplied here.)

*Fact 3 (logarithms).* $\ln(ab) = \ln a + \ln b$ and $e^{\ln x} = x$.

Now the argument. Call a hypothesis **bad** if its error exceeds $\varepsilon$. The true rule $c$ is never bad in a way that matters, because it has zero error and therefore agrees with every example. Fix one bad hypothesis $h$.

1. On one random example, $h$ agrees with the label with probability $1 - \mathrm{err}_D(h) \le 1 - \varepsilon$. Here $\mathrm{err}_D(h) > \varepsilon$ is the definition of bad.
2. Because the examples are independent, $h$ agrees with all $m$ labels with probability at most $(1-\varepsilon)^m$. This is the product rule applied to $m$ independent events.
3. By Fact 2 with $x = \varepsilon$, $(1-\varepsilon)^m \le e^{-\varepsilon m}$. So a fixed bad hypothesis survives all $m$ examples with probability at most $e^{-\varepsilon m}$.
4. There are at most $|H|$ bad hypotheses. By the union bound (Fact 1), the probability that at least one bad hypothesis survives is at most $|H|e^{-\varepsilon m}$.
5. The learner fails only if some bad hypothesis survives. So we need $|H|e^{-\varepsilon m} \le \delta$. Taking logarithms (Fact 3), this is equivalent to $\varepsilon m \ge \ln|H| + \ln(1/\delta)$, that is, $m \ge \frac{1}{\varepsilon}\left(\ln|H| + \ln\frac{1}{\delta}\right)$.

With this $m$, the complement rule says the event "no bad hypothesis survives" has probability at least $1-\delta$. On that event every consistent hypothesis has error at most $\varepsilon$, which proves the theorem. ([Zhang, CSC 665 PAC notes](https://zcc1307.github.io/courses/csc665fa19/notes/pac.pdf) gives the same structure, with the threshold written as a quantity $\mu$.)

**A worked illustration.** Take $|H| = 1000$, $\varepsilon = 0.1$ and $\delta = 0.05$. Then $\ln 1000 \approx 6.91$ and $\ln 20 \approx 3.00$, so $m \ge 10 \times 9.90 = 99$ examples suffice. Halving $\varepsilon$ doubles the requirement, while making $\delta$ twenty times smaller adds only $\ln 20$ to the bracket. The growth in $\ln|H|$ is also modest: multiplying $|H|$ by 10 adds $\ln 10 \approx 2.3$ to the bracket, so the requirement grows only logarithmically in the number of candidate rules. (These figures are the article's own arithmetic from the stated formula.)

**An interval example.** Suppose the true rule marks points in $[0,1]$ inside an unknown interval, and the learner returns the tightest interval containing all positive examples. Its errors come only from two end-strips, each with probability at most $\varepsilon$ under $D$. A strip of mass $\varepsilon$ is missed by all $m$ samples with probability at most $(1-\varepsilon)^m \le e^{-\varepsilon m}$, and a union bound over the two strips gives failure probability at most $2e^{-\varepsilon m}$. Setting this to $\delta$ gives $m \ge \ln(2/\delta)/\varepsilon$. For $\varepsilon = 0.1$ and $\delta = 0.05$, this is $\ln 40/0.1 \approx 36.9$, so 37 examples suffice. (This is the article's own derivation using the bound above; no source gives this specific count.)

## When labels are noisy, the requirement rises to 1/ε²

The realizable assumption says the true rule is in $H$, and real data often violates it. The **agnostic** setting drops the assumption. Labels may come from a distribution that no rule in $H$ explains perfectly, and the learner should then match the best rule in the class ([arXiv 2510.18057](https://arxiv.org/html/2510.18057); [Class Notes 67577](https://arxiv.org/pdf/0904.3664)). The target is

$$\mathrm{err}_D(\hat h) \le \min_{h\in H}\mathrm{err}_D(h) + \varepsilon.$$

The tool is **Hoeffding's inequality**. Let $X_1,\ldots,X_m$ be i.i.d. with values in $[0,1]$, and let $\bar X$ be their average. Then

$$P\big(|\bar X - E[X]| \ge t\big) \le 2e^{-2mt^2}.$$

Plainly: an average of many independent bounded values rarely strays far from its expected value, and the chance of straying by $t$ shrinks exponentially in $m$ ([Livni, COS-511](https://www.cs.princeton.edu/~rlivni/cos511/lectures/lect2.pdf); [Wikipedia, Hoeffding's inequality](https://en.wikipedia.org/wiki/Hoeffding's_inequality)). The inequality was proved by Wassily Hoeffding in 1963 ([Wikipedia, Hoeffding's inequality](https://en.wikipedia.org/wiki/Hoeffding's_inequality)). Its standard proof uses Hoeffding's lemma, which bounds the moment-generating function of a bounded variable, and that lemma is proved with Taylor's theorem ([Wikipedia, Hoeffding's lemma](https://en.wikipedia.org/wiki/Hoeffding's_lemma)). We take the inequality itself as given.

**Derivation of the agnostic bound.** For a fixed $h$, the training error $\mathrm{err}_S(h) = \frac{1}{m}\sum_{i=1}^m \mathbf{1}[h(x_i)\neq y_i]$ is the average of $m$ i.i.d. values in $\{0,1\}$, with expectation $\mathrm{err}_D(h)$. Applying Hoeffding with $t = \varepsilon/2$:

$$P\big(|\mathrm{err}_S(h) - \mathrm{err}_D(h)| \ge \varepsilon/2\big) \le 2e^{-2m(\varepsilon/2)^2} = 2e^{-m\varepsilon^2/2}.$$

A union bound over all $h \in H$ gives that, with probability at least $1-\delta$, every hypothesis has training error within $\varepsilon/2$ of its true error, provided $2|H|e^{-m\varepsilon^2/2} \le \delta$. Solving gives $m \ge \frac{2}{\varepsilon^2}\ln\frac{2|H|}{\delta} = \frac{2}{\varepsilon^2}\left(\ln|H| + \ln\frac{2}{\delta}\right)$.

Now the **empirical risk minimizer** (ERM) picks the $\hat h$ with the lowest training error. On the good event, let $h^*$ be the best rule in $H$. Then

$$\mathrm{err}_D(\hat h) \le \mathrm{err}_S(\hat h) + \tfrac{\varepsilon}{2} \le \mathrm{err}_S(h^*) + \tfrac{\varepsilon}{2} \le \mathrm{err}_D(h^*) + \varepsilon.$$

The middle inequality holds because ERM minimizes training error, and the last because $h^*$ is within $\varepsilon/2$ as well. The two half-gaps add up to $\varepsilon$ ([Livni, COS-511](https://www.cs.princeton.edu/~rlivni/cos511/lectures/lect2.pdf); [Zhang, CSC 665 PAC notes](https://zcc1307.github.io/courses/csc665fa19/notes/pac.pdf)). Finite classes have this uniform convergence property by exactly this argument ([MIT GradML](https://gradml.mit.edu/supervised/learnability_and_vc/); [Toulouse lecture notes](https://www.math.univ-toulouse.fr/~agarivie/sites/default/files/4_PAC_NFL_UC_0.pdf)).

The sources differ slightly in constants. Zhang uses a deviation $\mu$ with $\mu = \sqrt{(\ln|H| + \ln(2/\delta))/(2m)}$ and gets error $\varepsilon = 2\mu$, while Livni states the requirement as $m > \frac{2}{\varepsilon^2}\log\frac{2|H|}{\delta}$ with strict inequality. These are the same bound written two ways, since $\ln(2|H|/\delta) = \ln|H| + \ln(2/\delta)$.

| Setting | Sample size for finite $H$ | Scaling in $\varepsilon$ |
|---|---|---|
| Realizable (true rule in $H$) | $\frac{1}{\varepsilon}\left(\ln|H| + \ln\frac{1}{\delta}\right)$ | $1/\varepsilon$ |
| Agnostic (ERM, no assumption) | $\frac{2}{\varepsilon^2}\left(\ln|H| + \ln\frac{2}{\delta}\right)$ | $1/\varepsilon^2$ |

For the same $|H| = 1000$ and $\delta = 0.05$, the agnostic bound is $\frac{2}{\varepsilon^2}(6.91 + 3.69) \approx \frac{21.2}{\varepsilon^2}$, against about $\frac{9.9}{\varepsilon}$ in the realizable case. Halving $\varepsilon$ doubles the realizable requirement but quadruples the agnostic one. Removing the assumption that the rule is in the class therefore makes learning considerably more data-hungry. Sources also note that the agnostic setting is equivalent to empirical risk minimization via uniform convergence ([arXiv 2510.18057](https://arxiv.org/html/2510.18057)).

## Beyond finite classes: VC dimension, computation and extensions

Most real classes, such as all linear classifiers, are infinite, so the union bound over $|H|$ cannot be used. The **VC dimension** (named after Vapnik and Chervonenkis) replaces $\ln|H|$ as the measure of complexity. A set of points $S$ is **shattered** by a class if the class can produce every possible labelling of $S$. The VC dimension $d$ is the size of the largest set that can be shattered ([arXiv 1703.00729](https://arxiv.org/pdf/1703.00729); [Tewari, CMSC 35900 lecture 11](https://home.ttic.edu/~tewari/lectures/lecture11.pdf)).

The **fundamental theorem of PAC learning** states that a class is PAC learnable if and only if its VC dimension is finite, and it gives the sample complexity. In the realizable case,

$$C_1\cdot\frac{d + \ln(1/\delta)}{\varepsilon} \le m \le C_2\cdot\frac{d\ln(1/\varepsilon) + \ln(1/\delta)}{\varepsilon}$$

for constants $C_1, C_2$ ([arXiv 2510.13984](https://arxiv.org/pdf/2510.13984); [arXiv 2203.03046](https://arxiv.org/pdf/2203.03046)). The VC dimension thus plays the role $\ln|H|$ played: it counts how many distinctions the class can make. The sources do not say whether the $\ln(1/\varepsilon)$ factor can be removed in general. The agnostic version replaces $\varepsilon$ with $\varepsilon^2$ in the denominator ([arXiv 1709.02840](https://arxiv.org/pdf/1709.02840)).

Examples make the idea concrete. Unbounded intervals on the real line have VC dimension 2 ([Aschenbrenner, UCLA](https://www.math.ucla.edu/~matthias/pdf/Fields.pdf)), and axis-aligned rectangles in the plane have VC dimension 4 ([Tewari lecture 11](https://home.ttic.edu/~tewari/lectures/lecture11.pdf)). Half-spaces in $\mathbb{R}^d$, meaning linear classifiers of the form $\mathrm{sign}(w\cdot x - \theta)$ with weight vector $w$ and threshold $\theta$, have VC dimension $d+1$ ([Tewari lecture 11](https://home.ttic.edu/~tewari/lectures/lecture11.pdf)). For a beginner, in the plane a line with a threshold can shatter any 3 points that are not on one straight line, and no 4 points can be shattered. The same lecture notes that convex polygons in the plane have infinite VC dimension, so some natural classes are not PAC learnable by this criterion at all.

PAC also distinguishes learnability from efficient learnability. Pitt and Valiant showed that, unless RP = NP, there is no polynomial-time proper PAC learner for 3-term DNF formulas, and their proof reduces 3-colouring of graphs to the learning problem ([arXiv 2511.08791](https://arxiv.org/pdf/2511.08791)). A 1-term DNF is properly learnable, but proper learning of $t$-term DNF is NP-hard for any $t\ge 2$ ([arXiv 1911.06358](https://arxiv.org/pdf/1911.06358)). Valiant showed that $t$-term DNF can be learned efficiently when the output is allowed to be a CNF, an improper learner ([arXiv 1911.06358](https://arxiv.org/pdf/1911.06358)). Kearns and Valiant used cryptographic assumptions, such as the difficulty of inverting RSA or factoring Blum integers, to show that some classes cannot be learned efficiently, since a fast learner would break the cryptosystem ([Kearns and Valiant, JACM](https://www.cis.upenn.edu/~mkearns/papers/cryptojacm.pdf); [Springer encyclopedia entry](https://link.springer.com/rwe/10.1007/978-1-4939-2864-4_96)). Klivans and Sherstov show that learning the intersection of $n$ halfspaces in $n$ dimensions requires time $2^{n^\gamma}$ under a cryptographic assumption ([Klivans and Sherstov](https://www.cs.utexas.edu/~klivans/hs-hardness.pdf)). These hardness results depend on unproven assumptions such as RP ≠ NP or the security of cryptosystems.

Several extensions adjust the model. **Classification noise**, studied by Angluin and Laird, flips each label with probability $\eta < 1/2$. Angluin and Laird gave a polynomial-time algorithm for $k$-CNF formulas under this noise ([Angluin and Laird](https://link.springer.com/article/10.1023/A:1022873112823)). The sample complexity depends polynomially on $1/(1-2\eta)$ ([arXiv 1902.04629](https://arxiv.org/pdf/1902.04629)), so at $\eta = 1/2$ the labels carry no information and learning is impossible ([Wikipedia, Error tolerance](https://en.wikipedia.org/wiki/Error_tolerance_(PAC_learning))). **Online learning** counts mistakes rather than samples. Littlestone introduced the mistake-bound model, and a class's **Littlestone dimension** $d$ is the depth of its largest Littlestone tree; this dimension characterises the optimal mistake bound in the standard online setting ([Littlestone 1988](http://ai.stanford.edu/~pabbeel/depth_qual/littlestone1988.pdf); [Bousquet](https://web.math.princeton.edu/~rvan/tri201106.pdf)). Kearns, Schapire and Sellie showed that agnostic learning of conjunctions is generally NP-hard ([Kearns, Schapire and Sellie](https://link.springer.com/article/10.1007/BF00993468)).

The framework also has critics. A review argues that PAC learning "applies in a natural way to only a rather narrow, though very important, class of learning problems" ([Davis review](https://cs.nyu.edu/~davise/papers/Valiant.pdf)). A SIAM News review notes that only a rather small number of learning problems have been proved efficiently PAC-learnable ([SIAM News](https://www.siam.org/publications/siam-news/articles/pac-a-universal-framework-for-learning/)). The sources do not address directly how PAC bounds relate to the performance of large modern neural networks, so the framework's practical reach there is an open question.

## Conclusion

The central idea of PAC learning is that a learner can be judged by two dials. The accuracy dial $\varepsilon$ sets how wrong the learned rule may be on new cases, and the confidence dial $\delta$ sets how often the learner may fail. Under the realizable assumption, a finite set of candidate rules needs roughly $\frac{1}{\varepsilon}(\ln|H| + \ln\frac{1}{\delta})$ examples, and the logarithms make the requirement grow slowly with the number of candidates. Once the true rule may fall outside the class, the requirement becomes $\frac{2}{\varepsilon^2}(\ln|H| + \ln\frac{2}{\delta})$, which is markedly more demanding. The VC dimension extends this reasoning to infinite classes, and the fundamental theorem makes finite VC dimension the exact condition for PAC learnability.

Two cautions follow for a reader who wants to apply the theory. First, learnability in principle is not the same as efficient learnability: some classes are learnable only by changing the form of the output, and others are hard under standard complexity or cryptographic assumptions. Second, the guarantees are worst-case over all distributions, so they can be pessimistic for particular data. Understanding the formulas here gives a principled way to ask how much data a learner needs, and what assumptions that answer depends on.
