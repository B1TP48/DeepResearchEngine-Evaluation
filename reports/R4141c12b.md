# Unrestricted Self-Improvement Blocks an Indefinite Alignment Guarantee

**Verdict: no unconditional mathematical guarantee exists, and none is known how to construct, that a self-improving AI will maintain alignment with human values indefinitely through recursive self-modification; for unrestricted systems the general guarantee is ruled out by computability and self-trust results, but no impossibility theorem covers every restricted architecture.** Rice’s theorem blocks deciding any non-trivial semantic property over arbitrary programs, while Löb/Gödel block a consistent proof system from certifying an equal-strength successor’s soundness, so proof-based tiling chains are finite ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf); [Vingean Reflection](https://intelligence.org/files/VingeanReflection.pdf)). The target is also not a single formal object: inverse reinforcement learning identifies rewards only up to an equivalence class, social-choice theorems block neutral aggregation, and Goodhart results show proxies degrade under optimization ([Amin & Singh](https://arxiv.org/html/1601.06569v1); [Stanford Encyclopedia of Philosophy, “Social Choice Theory”](https://plato.stanford.edu/entries/social-choice/); [Skalse et al.](https://neurips.cc/virtual/2022/poster/52878)). Positive results exist only relative to a fixed utility, specification, verifier and modification class—Gödel-machine optimality relative to an axiom system, proof-carrying code and CompCert property preservation, SEVerA per-call contracts—not alignment with human values ([Schmidhuber](https://arxiv.org/pdf/cs/0309048v5); [Necula](https://dl.acm.org/doi/pdf/10.1145/263699.263712); [CompCert](https://inria.hal.science/hal-03882598v1/file/main.pdf); [SEVerA](https://arxiv.org/abs/2603.25111)). The precise logical status is “no known construction and no impossibility theorem for alignment under recursive self-modification”; the only prominent peer-reviewed impossibility claim concerns containment of arbitrary programs and was rebutted on scope ([Alfonseca et al., JAIR](https://www.jair.org/index.php/jair/article/download/12202/26642/); [CSER](https://www.cser.ac.uk/work/response-superintelligence-contained/)). A definitive yes is therefore false as an established result; a definitive no is not proved for all architectures, but an unconditional indefinite guarantee for unrestricted recursive self-modification cannot be established.

## Unrestricted self-modification cannot carry an unconditional proof

Löb’s theorem, in the tiling form, states that for any formula φ and any theory T at least as powerful as PA, “T ⊢ □_T⌜φ⌉ → φ ⟺ T ⊢ φ”; with φ = ⊥ it yields the Second Incompleteness Theorem ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)). The informal consequence is that T cannot say “I trust that if any proof of φ exists from my axioms, then φ is true”; it can only react to particular proofs, so it cannot approve its own behavioural principles under reflection ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)). In the tiling formalism, a parent A¹ must prove a uniform soundness schema over its successor A⁰’s axiom system, ∀φ: A¹ ⊩ ∀x: □₀[φ(x)] → φ(x), which forces the parent’s system to be strictly stronger than the child’s ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)). The proved consequence is a finite “telomere”: if each ancestor requires a more powerful proof system than its offspring, then an agent A_α can create A_β only when β < α, so it can create only finite chains of descendants, and all well-founded systems of trust above T reach the base system after a finite descent ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)). The companion procrastination paradox shows the other horn: an agent that assumes the reflection schema REF(T) can derive its goal, then its negation, implying T is inconsistent, or it can defer action forever ([Vingean Reflection](https://intelligence.org/files/VingeanReflection.pdf)). The AGI-14 paper states the dilemma directly: naive approaches either allow an agent to put off an important task forever or fail to justify even obviously safe rewrites ([Fallenstein & Soares, AGI-14](https://intelligence.org/files/ProblemsofSelfReference.pdf)).

The other results close different routes rather than adding a separate self-trust theorem. Tarski-style undefinability says no expressive language contains its own truth predicate, because the liar sentence G ↔ True(⌜¬G⌉) gives G ↔ ¬G ([Definability of Truth in Probabilistic Logic](http://intelligence.org/files/DefinabilityTruthDraft.pdf)). Rice’s theorem says no non-trivial property of output can be determined over arbitrary programs, although an AI “may choose to work within a more restrictive space of programs which it can understand” ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)). Thus Löb/Gödel attack self-trust specifically, Tarski blocks a truth predicate for the agent’s own language, and Rice blocks architecture-general inspection of arbitrary successor code; none by itself proves that every carefully restricted self-modifying system is unverifiable ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf); [Definability of Truth](http://intelligence.org/files/DefinabilityTruthDraft.pdf)). A 2026 preprint claims that one-step preservation is “Rice’s theorem one level up” when the rewrite depends only on behaviour, and at least as hard as halting when it reads code, with “no tower of supervisors” lowering the problem ([Gumbau Mezquita, arXiv:2606.28639](https://arxiv.org/abs/2606.28639)). That preprint is single-author, non-peer-reviewed, and states that its structuring and formal-language editing were conducted with AI assistance, so its claims should be treated as unvetted rather than established ([arXiv:2606.28639v2](https://arxiv.org/html/2606.28639v2)).

The documented escapes relocate the unproved assumption rather than discharge it. Marcello’s Waterfall is consistent and lets each theory trust the next, but it has only nonstandard models, including models where ZF is inconsistent, and it succumbs to the procrastination paradox ([Fallenstein’s Monster](http://intelligence.org/files/FallensteinsMonster.pdf)). Parametric Polymorphism has standard models and avoids procrastination, but the agent can never deduce κ > 0, and deployable proof strength depends on successor depth; goal subdivision is fixed by the designers or by ordinal indices ([Fallenstein’s Monster](http://intelligence.org/files/FallensteinsMonster.pdf)). The grafted “Baby Abomination” combines a Π₁-sound waterfall with Parametric Polymorphism, but the note presents it as combining two flawed solutions, not removing the obstacle ([Fallenstein’s Monster](http://intelligence.org/files/FallensteinsMonster.pdf)). The probabilistic truth-predicate route is blocked by Tarski and, in its probabilistic replacement, has its own procrastination-style problem per Fallenstein (2014b) ([Definability of Truth](http://intelligence.org/files/DefinabilityTruthDraft.pdf); [Vingean Reflection](https://intelligence.org/files/VingeanReflection.pdf)).

## Human values have no formal target a proof could preserve

No consistent, sufficiently complete formal specification of human values exists. The complexity-of-value thesis argues that a specification of worthwhile happiness is likely “thousands or millions of bytes,” that a 10,000-byte exact specification with only 9,500 bytes may produce “5%, 0%, or negative value rather than 95%,” and that most 1,000-byte strings are not compressible to 20 bytes ([Complexity of value](https://www.lesswrong.com/w/complexity-of-value?version=1.2.0)). Coherent Extrapolated Volition, the best-known attempt to avoid hand-specification, is criticized because human values are “not stable or fixed” but shaped by context and culture, so extrapolation could replace original desires rather than reveal them ([Wikipedia, “Coherent extrapolated volition”](https://en.m.wikipedia.org/wiki/Coherent_extrapolated_volition)). Baum argues that the normative basis of social-choice AI ethics is weak because “there is no one single aggregate ethical view of society,” and designers must settle “standing,” “measurement” and “aggregation” up front rather than let the AI infer them ([Baum, AI & Society 2020](http://sethbaum.com/ac/2020_SocialChoice.pdf)).

Social-choice theory makes the aggregation layer an impossibility problem in its own right. Arrow proved that no method aggregates the preferences of two or more individuals over three or more alternatives into collective preferences while satisfying five plausible axioms, and Condorcet cycles can make majority preferences intransitive even when every individual is transitive ([Stanford Encyclopedia of Philosophy, “Social Choice Theory”](https://plato.stanford.edu/entries/social-choice/)). Sen’s liberal paradox shows no rule satisfies universal domain, acyclicity, weak Pareto and minimal liberalism, and Gibbard–Satterthwaite shows no rule satisfies universal domain, non-dictatorship, the range constraint, resoluteness and strategy-proofness ([SEP archive, “Social Choice Theory”](https://seop.illc.uva.nl/archives/spr2026/entries/social-choice/index.html)). Enriching the informational basis to cardinal, interpersonally comparable welfare escapes Arrow, but Harsanyi-type derivations remain “consistent with weighted and unweighted versions of utilitarianism and its rival prioritarianism,” so the aggregation rule is a substantive moral choice, not a neutral fact ([Kelleher, Oxford University Press 2025](https://preview.academic.oup.com/book/59438/chapter-abstract/500098651)). RLHF and constitutional AI must still “aggregate the input into consistent data about ‘collective’ preferences,” which is exactly where social choice applies ([Conitzer et al.](https://ar5iv.labs.arxiv.org/html/2404.10271v1)).

Metaethics and value learning deepen the underdetermination. Under anti-realism there is no mind-independent moral fact for an alignment property to track, while under realism a unique truth may exist but goods may be incommensurable, so the target can be only a partial order rather than a scalar function ([Stanford Encyclopedia of Philosophy, “Moral Anti-Realism”](https://plato.stanford.edu/entries/moral-anti-realism/); [Stanford Encyclopedia of Philosophy, “Incommensurable Values”](https://seop.illc.uva.nl/archives/win2024/entries/value-incommensurable/)). Moral uncertainty requires deciding whether theories are ordinal, cardinal, or intertheoretically comparable, and the comparison rule is itself contested ([MacAskill, Bykvist & Ord, *Moral Uncertainty*](https://academic.oup.com/book/32361)). Inverse reinforcement learning shows the behavioural data do not pin down a unique value function: there may be “infinitely many reward functions consistent with any observed policy,” with constant rewards, rescaling, and experimental insufficiency as separate causes, and even perfect knowledge of the optimal policy leaves rewards “not fully identifiable” ([Amin & Singh](https://arxiv.org/html/1601.06569v1); [Cao, Cohen & Szpruch](https://ar5iv.labs.arxiv.org/html/2106.03498)). Goodhart results then show that optimizing a proxy is not guaranteed to improve the true objective: over all stochastic policies, two reward functions can be “unhackable” only if one is constant, while for deterministic policies non-trivial unhackable pairs exist ([Skalse et al., NeurIPS 2022](https://neurips.cc/virtual/2022/poster/52878)). Karwowski et al. prove that to “provably avoid Goodharting” one must stop optimization at a point with no Goodharting for any reward in the uncertainty set, and the extremal and causal variants are especially relevant to self-modification because the system can move the state distribution outside the proxy’s validity region ([Karwowski et al.](https://ar5iv.labs.arxiv.org/html/2310.09144); [Manheim & Garrabrant](https://arxiv.org/abs/1803.04585)). DeepMind’s catalogue defines specification gaming as satisfying “the literal specification of an objective without achieving the intended outcome” and reports around 60 examples ([DeepMind Safety Research](https://deepmindsafetyresearch.medium.com/specification-gaming-the-flip-side-of-ai-ingenuity-2f7b1a5c0c8b)). A rigorous alignment-preservation statement must therefore specify the value model S up to behavioural equivalence, population P, aggregation rule A, uncertainty set U, modification class M, and an ε bound; even then it is conditional on normative choices, and “the system remains aligned with human values” is not a well-formed mathematical predicate without them ([Skalse et al.](https://neurips.cc/virtual/2022/poster/52878); [Cao et al.](https://ar5iv.labs.arxiv.org/html/2106.03498); [Baum](http://sethbaum.com/ac/2020_SocialChoice.pdf); [Karwowski et al.](https://ar5iv.labs.arxiv.org/html/2310.09144)).

## Positive theorems guarantee specification-relative safety, not alignment

| Approach | What is actually proved | Why it does not answer the question |
|---|---|---|
| Gödel machine | A rewrite executes only after a proof of higher expected utility; Theorem 4.1 claims “globally optimal self-change” relative to the axiom system, resource limits and initial proof searcher; utility rewrites only if the present utility function proves them useful ([Schmidhuber](https://arxiv.org/pdf/cs/0309048v5); [Gödel Machine FAQ](https://people.idsia.ch/~juergen/gmfaq.html)) | The utility function is an axiom supplied at design time; consistency of the arithmetic system is assumed, not proved; pathological environments can make target theorems unprovable; a misspecified utility is preserved, not corrected ([Schmidhuber](https://arxiv.org/pdf/cs/0309048v5)) |
| Proof-carrying code and CompCert | PCC certifies that code adheres to a previously defined safety policy if the proof validates; CompCert’s theorem says every observable behaviour of compiled code is a possible behaviour of the source ([Necula, POPL 1997](https://dl.acm.org/doi/pdf/10.1145/263699.263712); [CompCert](https://inria.hal.science/hal-03882598v1/file/main.pdf)) | Both are conservative relative to a supplied specification and trusted checker; neither creates value content, and a system that can modify its verifier or specification escapes the guarantee ([Necula](https://dl.acm.org/doi/pdf/10.1145/263699.263712); [CompCert](https://inria.hal.science/hal-03882598v1/file/main.pdf)) |
| SEVerA | Wraps an LLM in a rejection sampler with a verified fallback, so “every returned output satisfies the contract for any input and parameter setting”; reports zero constraint violations on Dafny, symbolic math and τ²-bench ([SEVerA](https://arxiv.org/abs/2603.25111)) | The invariant is a per-call input–output contract, not alignment; the planner remains free inside the contract, and no result covers an unbounded sequence of generations ([SEVerA](https://arxiv.org/abs/2603.25111)) |
| Everitt et al. safe self-modification | For a perfectly rational agent with modification-independent value function, self-modification is harmless “if and only if” the value function anticipates self-modification and evaluates the future with the current utility; Theorem 3.2 says realistic policy-modifying agents make safe modifications ([Everitt et al., AGI 2016](https://arxiv.org/abs/1605.03142); [PDF](https://www.tomeveritt.se/papers/AGI16-sm.pdf)) | The invariant is “no loss of expected u₁-utility,” not human values; perfect rationality and modification-independent u₁ are assumed, and the paper concedes agents may self-modify into “non-value learning, non-corrigible, and non-exploring agents” ([Everitt et al.](https://www.tomeveritt.se/papers/AGI16-sm.pdf)) |
| Tiling constructions | Indefinitely tiling sequences maintaining trust in the same mathematical system are technically possible ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)) | The authors call the methods implausible as basic agent architectures and leave the fundamental decision criterion open; the invariant is proof-theoretic trust, not “the successor has the right goal” ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)) |
| Corrigibility, off-switch, interruptibility, quantilizers | Shutdown in a small game; off-policy safe interruptibility; a 1/q quantilizer cost bound relative to a base distribution ([Corrigibility](https://intelligence.org/files/Corrigibility.pdf); [Off-Switch Game](https://arxiv.org/abs/1611.08219); [Orseau & Armstrong](https://dl.acm.org/doi/10.5555/3020948.3021006); [Quantilizers](https://intelligence.org/files/QuantilizersSaferAlternative.pdf)) | Corrigibility’s Theorem 4 is explicitly negative: there is no cost the utility-indifference agent will pay to ensure successors obey shutdown, so shutdown behaviour is not propagated through self-modification ([Corrigibility](https://intelligence.org/files/Corrigibility.pdf)); the others do not model objective rewriting, and quantilizer safety is relative to γ ([Quantilizers](https://intelligence.org/files/QuantilizersSaferAlternative.pdf)) |
| Debate, iterated amplification, Darwin Gödel Machine | Debate gives a complexity-theoretic analogy plus an MNIST experiment; IDA reports algorithmic-environment learning; DGM empirically validates code changes on benchmarks ([Debate](https://ar5iv.labs.arxiv.org/html/1805.00899); [IDA](https://arxiv.org/abs/1810.08575); [DGM](https://arxiv.org/abs/2505.22954)) | No alignment theorem exists for debate or IDA; DGM states that proving most changes net beneficial “is impossible in practice” and substitutes benchmark gains—SWE-bench from 20.0% to 50.0% and Polyglot from 14.2% to 30.7%—plus sandboxing and human oversight ([DGM](https://arxiv.org/abs/2505.22954)) |

The strongest published “all successors” result is Everitt et al.’s Theorem 3.2, but it is bounded twice: the invariant is utility preservation under a fixed u₁, and the theorem assumes perfect rationality. Tětek, Sklenka and Gavenčiak show that with bounded rationality self-modification may cause “exponential deterioration in performance and gradual misalignment of a previously aligned agent,” with misalignment growing exponentially under one form of imperfection ([Tětek et al.](https://arxiv.org/abs/2011.06275)). The Gödel machine, Everitt’s realistic value function and corrigibility’s utility indifference share the same structure: the current utility function is the arbiter of all future changes, so whatever the initial objective encodes—including its errors—is preserved ([Schmidhuber](https://arxiv.org/pdf/cs/0309048v5); [Everitt et al.](https://www.tomeveritt.se/papers/AGI16-sm.pdf); [Corrigibility](https://intelligence.org/files/Corrigibility.pdf)). Tiling answers “can trust be transmitted indefinitely?” with a qualified yes, but not “is the transmitted goal the right goal?” ([Tiling Agents](https://intelligence.org/files/TilingAgents.pdf)).

## Finite proofs cover indefinite horizons only for fixed models

A finite proof can establish an indefinite safety property when the transition relation and specification are fixed. An inductive invariant satisfies initiation, consecution and safety—Init ⇒ Inv, Inv ∧ R ⇒ Inv′, and Inv ⇒ post—so if such an invariant exists, the transition system satisfies the property for all reachable states ([Property Directed Self Composition](https://ar5iv.labs.arxiv.org/html/1905.07705)). seL4 is a concrete example: its proofs go down to C and, for some architectures, binary code, but they assume about 340 lines of ARM assembly, hardware correctness, about 1,200 lines of boot code, and DMA behaviour, and the virtual-memory reasoning relies on human judgement that all necessary conditions were captured ([seL4: What the Proofs Assume](https://sel4.systems/Verification/assumptions.html)). Coinduction supplies the greatest-fixpoint argument for safety, while well-founded rankings supply liveness; the trusted base—proof checker, compiler, hardware and boot code—does not disappear ([seL4](https://sel4.systems/Verification/assumptions.html)).

Self-modification breaks the fixed-code assumption. Hoare logic and type systems “consistently assume that program code stored in memory is fixed and immutable,” and GCAP extends Hoare-style reasoning to runtime code manipulation by treating code as data, but it verifies specific assembly programs against human-supplied specifications, including opcode modification, self-growing code and OS boot loaders ([Certified Self-Modifying Code](http://www.cs.yale.edu/flint/publications/smc.pdf)). No documented system verifies an AI that rewrites its own objective, and Rice’s theorem makes every non-trivial semantic property of arbitrary programs undecidable, so “every reachable rewritten program satisfies P” is itself non-trivial for a Turing-complete self-modifying system ([Rice’s theorem](https://en.wikipedia.org/wiki/Rice%27s_theorem); [Certified Self-Modifying Code](http://www.cs.yale.edu/flint/publications/smc.pdf)).

Current neural-network verification proves only local, bounded properties. VNN-COMP 2025 had 8 teams and 25 benchmarks, with networks from 4k to 68M parameters, input dimensions from 2 to 9,408, and up to 11k input regions; α-β-CROWN reported 433 verified and 647 falsified instances with a normalised score of 100.0, while NNV reported 172 verified and 176 falsified with 32.2, and the competition states that neural-network verification “remains an open problem” ([VNN-COMP 2025](https://arxiv.org/html/2512.19007v1); [ETH Zurich lecture](https://eth-sri.github.io/downloads/rtai26/LECTURE4_DEEPPOLY.pdf)). Closed-loop verification exists only over a time horizon—CORA verifies a neural-network controller “while keeping a safe distance over some time horizon”—and complete branch-and-bound or MIP methods are exponential in the worst case, while incomplete bound propagation can return unknown or false alarms ([VNN-COMP 2025](https://arxiv.org/html/2512.19007v1)).

Practice substitutes structured, probabilistic assurance for proof. UL 4600, published on 1 April 2020, requires a claim-based safety case and explicitly “does not aim to provide … Guarantee that conformance with the standard would ensure that the product is safe” ([VTT, UL 4600](https://cris.vtt.fi/files/43567116/2021_01_15_UL4600_FIMA_workshop.pdf)). GSN Community Standard v3, May 2021, structures claims, strategies, solutions, context and assumptions, but does not itself establish their truth ([GSN Community Standard v3](https://scsc.uk/r141C:1?t=1)). The UK AISI template defines a safety case as “a structured, evidence-based argument” that risk is acceptable and describes itself as “a proof of concept” ([UK AISI](https://www.aisi.gov.uk/research/safety-case-template-for-frontier-ai-a-cyber-inability-argument-2)). Anthropic states that “it is probably infeasible to mathematically guarantee the real-world safety of an AI system,” and AI-control evaluations measure backdoor rates empirically rather than prove absence ([Anthropic, safety cases](https://alignment.anthropic.com/2024/safety-cases/); [AI Control](https://arxiv.org/html/2312.06942v5)). Anthropic’s 2023 position is that “no one knows how to train very powerful AI systems to be robustly helpful, honest, and harmless,” OpenAI’s 2023 announcement says “we don’t have a solution for steering or controlling a potentially superintelligent AI,” and DeepMind’s 2025 approach is explicitly exploratory, sets aside goal drift and novel superintelligence risks, and claims robustness only for “the next several scales” ([Anthropic](https://www.anthropic.com/news/core-views-on-ai-safety); [Reuters report](https://tribune.com.pk/); [DeepMind](https://deepmindsafetyresearch.medium.com/an-approach-to-technical-agi-safety-and-security-25928819fbc6)). Framework uptake is documented—Frontier AI Safety Frameworks “more than doubled in 2025”—but governance focuses “largely on transparency and risk assessment,” not deductive guarantee ([International AI Safety Report 2025](https://browse-export.arxiv.org/abs/2511.19863)).

## Published verdicts converge on no known construction, not impossibility

No peer-reviewed paper asserts a definitive yes to alignment under recursive self-modification, and none asserts a definitive no. The closest published impossibility claim is Alfonseca et al., who argue in JAIR that total containment is “in principle, impossible” because containing a universal-Turing-machine-equivalent program requires simulating it ([Alfonseca et al., JAIR](https://www.jair.org/index.php/jair/article/download/12202/26642/)). CSER’s rebuttal says the argument goes back to Rice in 1953, concerns arbitrary programs rather than particular ones, and depends on the hidden assumption that the AI might execute arbitrary programs as subroutines: “the AI itself could be in principle engineered to not execute arbitrary subroutines” ([CSER](https://www.cser.ac.uk/work/response-superintelligence-contained/)). Bostrom’s orthogonality and instrumental-convergence theses support the independence of capability and final goals, but they are existence claims about the space of agents, not a proof that no guarantee is constructible ([Bostrom, *Minds and Machines*](https://library.mpifg.de/)). The pessimistic case is consistently framed as practical tractability—“things we are not on course to solve in practice in time”—and Lawfare’s review of *If Anyone Builds It, Everyone Dies* says the book’s “central thesis remains unproven” and hinges on three unsettled questions ([MIRI](https://intelligence.org/); [Lawfare](https://www.lawfaremedia.org/article/the-case-for-ai-doom-rests-on-three-unsettled-questions)).

The Guaranteed Safe AI programme specifies what a formal guarantee would consist of—a world model, a safety specification, and a verifier issuing “an auditable proof certificate that the AI satisfies the safety specification relative to the world model”—but presents this as an agenda with technical challenges, and argues that experimental tests alone are insufficient ([Dalrymple et al., arXiv:2405.06624](https://arxiv.org/abs/2405.06624)). Safety-case work defines the target probabilistically, as “a structured rationale that AI systems are unlikely to cause a catastrophe,” organised around inability, control, trustworthiness and deference arguments ([Clymer et al.](https://arxiv-org.ezproxy.obspm.fr/html/2403.10462v2)). A community critique adds that even formal guarantees could be gamed by steganographic dangerous effects hidden in verified solutions, so the residual gap is the specification/verification interface between a formal model and the world ([LessWrong](https://www.greaterwrong.com/)).

The logical status is therefore **“no known construction, and no impossibility theorem for the alignment question,” with one narrow impossibility result for containment/verification of arbitrary programs.** An impossibility proof for the assignment’s question would need a formal model of the system including its self-modification operator and the space of reachable successors, a formal alignment predicate over behaviours or values, a theorem quantifying over all reachable modifications, and a justification that the model is faithful ([CSER](https://www.cser.ac.uk/work/response-superintelligence-contained/); [Dalrymple et al.](https://arxiv.org/abs/2405.06624)). Rice-style results quantify over arbitrary programs and cannot by themselves yield a negative verdict about a specified architecture; conversely, a positive result relative to a world model is conditional and inherits the fidelity of that model ([CSER](https://www.cser.ac.uk/work/response-superintelligence-contained/); [Dalrymple et al.](https://arxiv.org/abs/2405.06624)). Both camps converge on the proposition that no unconditional indefinite guarantee currently exists or is known how to construct, and that the only tractable guarantees on offer are conditional—relative to a formal world model and safety specification, or to restricted architectures and self-modification classes ([Anthropic](https://www.anthropic.com/news/core-views-on-ai-safety); [DeepMind](https://deepmindsafetyresearch.medium.com/an-approach-to-technical-agi-safety-and-security-25928819fbc6); [Lawfare](https://www.lawfaremedia.org/article/the-case-for-ai-doom-rests-on-three-unsettled-questions)).

## Conclusion

The question’s answer is negative in the only sense that can be defended today: an unconditional mathematical guarantee of indefinite alignment with human values under recursive self-modification is not available and cannot be derived for unrestricted systems, because Rice blocks general semantic certification, Löb/Gödel block same-strength successor trust, and the value target itself is underdetermined by identifiability, social choice and Goodhart results. That is not the same as a proved impossibility for every restricted architecture: no theorem establishes that all carefully bounded self-modifying systems must fail, and the documented positive results—Gödel-machine optimality, PCC/CompCert, SEVerA, Everitt’s safe-modification theorem, tiling—show that specification-relative guarantees can be built. The unresolved work is to specify the value model, aggregation rule, uncertainty set and modification class, keep the verifier and specification outside the modification boundary, and prove an invariant over all reachable successors—none of which any source establishes for human values in general.

The practical implication is that claims of “mathematical guarantee of alignment” outrun the evidence; deployment arguments in frontier AI are safety cases, empirical control and bounded-horizon assurance, not indefinite proofs. A genuine guarantee would be conditional and narrow: “for this formal value specification, this aggregation rule, this environment class and this restricted rewrite class, the system remains ε-optimal or contract-compliant.” Even that remains open for real human populations, because the specification would be a stipulation rather than a discovery.
